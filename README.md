# Shapley-Shubik Index

Скрипт считает индекс Шепли-Шубика для взвешенной игры голосования группы из 33 человек. Игра простая: коалиция
побеждает, если сумма весов её участников не меньше кворума, и проигрывает иначе. Для такой игры вектор Шепли и индекс
Шепли-Шубика совпадают.

Кворум задан как простое большинство, то есть строго больше половины суммарного веса. При сумме весов 72 это дает кворум
37. Значение легко поменять в переменной `quota` внутри блока `if __name__ == "__main__"`.

Прямой перебор всех перестановок для 33 игроков невозможен, потому что 33! это астрономическое число. Вместо этого
используется динамическое программирование: для каждого игрока считается распределение сумм весов среди подмножеств
остальных участников по размеру коалиции, и по нему определяется, в каких коалициях этот игрок оказывается решающим.

## Запуск

```
python3 shapley_shubik.py
```

Скрипт выводит таблицу игроков, отсортированную по убыванию индекса, и проверочную сумму всех индексов, которая должна
быть равна единице.
